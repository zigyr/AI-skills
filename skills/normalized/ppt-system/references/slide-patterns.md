# Slide Pattern Reference

## Purpose

A curated reference of effective slide design patterns observed in industry-leading presentations. These are **design knowledge references** — they inform the orchestrator's aesthetic judgment but are not enforced as rules.

---

## Apple Keynote Style

### Characteristics

- **Minimal text** — often a single word or short phrase per slide
- **Emotional imagery** — full-bleed photography that creates mood
- **Strong typography** — San Francisco (or similar geometric sans) at large scale
- **One core message per slide** — ruthlessly edited to a single idea
- **Dark or light immersive backgrounds** — rarely white; deep black or rich color washes
- **Generous whitespace** — the content breathes, often occupying only 20–30% of the canvas

### Common Patterns

| Pattern | Description | Example |
|---------|-------------|---------|
| Hero Image + Word | Full-bleed photo with 1–2 words overlaid | "Innovation." over a product shot |
| The Single Number | One massive statistic, no other content | Revenue figure at 120px bold |
| Feature Spotlight | Product close-up filling 70% of slide, feature name in corner | iPhone camera lens detail |
| Quote Pull | Customer or press quote at large scale, centered | "The best X we've ever tested" |

### When to Reference

- Product launches
- Brand-forward presentations
- Emotional storytelling
- High-budget keynotes where production value matters

### What to Extract

- The discipline of editing down to one idea
- The power of large typography with generous whitespace
- Image selection as the primary design decision
- Typography carries emotional weight — font choice is not neutral

## McKinsey / Consulting Style

### Characteristics

- **Insight-driven titles** — the slide title is the conclusion, not the topic
- **Evidence chain structure** — title → supporting points → data → source
- **Information-dense but ordered** — every element has a place in the argument
- **Consistent scaffolding** — heavy use of structured layouts (matrices, waterfalls, comparison tables)
- **Muted professional palette** — navy, grey, white, with single accent color
- **Charts are functional** — no decoration, data-first, direct labeling

### Common Patterns

| Pattern | Description | Example |
|---------|-------------|---------|
| Action Title + Body | Title states finding; body provides 3–5 supporting bullets + 1 chart | "Market growth is accelerating in APAC, driven by three factors" |
| Waterfall Bridge | Shows how X became Y through sequential +/− components | Revenue bridge: prior year → growth → decline → current year |
| 2×2 Matrix | Two axes create four quadrants, each with a strategic label | Market attractiveness vs competitive position |
| Mekko / Marimekko | Bar chart where column width encodes a second variable | Market size (width) × share (height) per segment |

### When to Reference

- Strategy documents
- Board presentations
- Consulting deliverables
- Any deck where the audience will read the slides afterward as a standalone document

### What to Extract

- Title as conclusion — the slide body exists to prove the title
- Structured layouts reduce cognitive overhead for data-heavy content
- Every visual element must earn its place in the argument
- Source attribution builds credibility

## Startup Pitch Deck Style

### Characteristics

- **Story-driven** — slides follow a narrative arc designed to build conviction
- **Traction-forward** — numbers and proof points appear early and prominently
- **Vision + evidence balance** — alternating aspirational and evidentiary slides
- **Clean, modern aesthetic** — sans-serif, bold colors, icon-heavy, minimal text
- **Problem/solution framing** — the core structure that drives the entire deck

### Common Patterns

| Pattern | Description | Example |
|---------|-------------|---------|
| Problem Slide | State the problem in the audience's language, make it visceral | "Small businesses spend 15 hrs/week on manual invoicing" |
| Solution Demo | Product screenshot or mockup with 3 key benefits called out | UI screenshot + 3 annotation callouts |
| Traction Slide | Key metrics displayed as large numbers with upward trend indicators | "50K MAU → 120K MAU in 6 months" with sparkline |
| Team Slide | Headshots + 1-line credential per person, logos of past companies | Photo grid with company logos underneath |
| Ask Slide | Single slide stating the ask, use of funds, and projected outcome | "$2M Seed → 18 months runway → $10M ARR target" |

### When to Reference

- Fundraising decks
- Startup demo days
- Internal innovation pitches
- Any presentation with a "convince to act" goal

### What to Extract

- The narrative arc is the primary design constraint
- Traction data should be impossible to miss (large, prominent, early)
- Every slide should answer "why should I believe this?"
- The ask slide is the destination — the entire deck builds toward it

## Futuristic / Tech Style

### Characteristics

- **Dark backgrounds** — deep black, navy, or dark gradient
- **High contrast** — bright accents (cyan, neon blue, white) on dark
- **Geometric decoration** — thin lines, grids, glows, particle effects
- **Large whitespace** — low information density, high visual impact
- **Sans-serif, often wide or light weight** — Inter, Space Grotesk, or similar
- **Animation-friendly** — layouts designed with reveal animations in mind

### Common Patterns

| Pattern | Description | Example |
|---------|-------------|---------|
| Center Focus | One element dead center, surrounded by emptiness | A single icon or word floating in dark space |
| Grid Overlay | Subtle grid lines on background, content on top | Cybersecurity or AI topic slides |
| Glow Accent | Thin glowing lines or borders around key elements | Framing a key metric or product name |
| Split Field | Diagonal or curved division between dark zones | Two-topic comparison with dramatic visual separation |

### When to Reference

- Tech product launches
- AI / Web3 / cybersecurity presentations
- Developer conferences
- Any presentation where "forward-looking" is a core message

### What to Extract

- Dark backgrounds create perceived depth and focus
- Color accents do more work when the palette is restrained
- Geometric precision (thin lines, exact spacing) signals technical competence
- Low density + high contrast = premium feel

## Minimalist Style

### Characteristics

- **Single focal point per slide** — everything else is removed
- **Restrained color** — often monochrome or one-color + white + black
- **Typography as the primary visual element** — font weight and size create all hierarchy
- **No decorative elements** — no gradients, no shadows, no icons unless essential
- **Extreme whitespace** — content often occupies the center 30–40% of the slide
- **Grid-based alignment** — Swiss/International Style influence

### Common Patterns

| Pattern | Description | Example |
|---------|-------------|---------|
| The Statement | One sentence, centered, nothing else | "We were wrong about remote work." |
| The Split | One word left, one word right, space between | "Problem" | "Solution" |
| The Stack | 3–5 words stacked vertically with generous line height | DESIGN / BUILD / LAUNCH / LEARN |
| The Contrast | Black slide with white text, then white slide with black text | Section transition pairs |

### When to Reference

- Design portfolio presentations
- Academic / research talks
- Architecture / fashion / luxury brand decks
- Any context where restraint signals confidence

### What to Extract

- Removal is the primary design act — start full, then cut
- When typography is the only tool, every typesetting decision matters
- Silence (empty space) creates gravity around what remains
- Minimalism only works with absolute execution precision

## Dashboard / Data Style

### Characteristics

- **Data-first layout** — numbers and charts drive the visual structure
- **Card-based organization** — each metric or chart lives in a defined container
- **Consistent chart grammar** — all visualizations share color, font, and style
- **Minimal annotation** — direct labeling, no chartjunk, clean axes
- **Hierarchical density** — primary KPI largest, secondary metrics smaller, details smallest

### Common Patterns

| Pattern | Description | Example |
|---------|-------------|---------|
| Hero KPI + Sparklines | One giant number with 2–3 mini trend charts beneath | Revenue with monthly trend sparkline |
| Metric Cards Row | 3–4 equal cards across the slide, each with number + label | MAU / Revenue / Churn / CAC in a row |
| Chart Focus | One chart occupies 60–70% of the slide, minimal supporting text | Line chart showing 5-year growth |
| Comparison Dashboard | Two columns of metrics for before/after or A/B | Old vs New feature adoption rates |

### When to Reference

- Quarterly business reviews
- Analytics presentations
- Operations dashboards
- Any data-heavy reporting context

### What to Extract

- Data hierarchy must be visually encoded (size, position, color)
- Chart styling must be unified across the entire deck
- Numbers need breathing room — don't crowd metrics
- Direct labeling > legends (reduces eye movement)

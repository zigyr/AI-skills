# Metrics Slide Grammar

## Use Case

Present quantitative evidence as the primary message. The number itself is the hero — text supports, not leads.

Typical scenarios:
- Revenue, growth, or performance KPIs
- Market size or share data
- Survey results with a single headline number
- Before/after impact quantification

## Narrative Role

- **validation** — provides evidence for a claim
- **proof** — establishes credibility through data
- **emphasis** — makes a number the center of attention

## Layout Pattern

**Large-number focus layout** — a single dominant KPI occupies the primary visual space.

Primary structure:
- Dominant number (large type, high contrast)
- Short label (what the number represents)
- Optional: mini context (comparison, trend direction, unit)

Supporting elements (if needed):
- Up to 2 secondary metrics in smaller scale
- 1 supporting visualization (sparkline, small bar, icon indicator)
- Source line (small, low-contrast)

Variants:
- Single hero number (purest form)
- 2–3 metric cards in a row (equal weight)
- Hero number + trend sparkline

## Information Density

**Medium.** Information is minimal but visually dominant.

Maximum:
- 3 primary metrics total
- 1 supporting visualization
- Zero paragraphs

## Content Constraints

- The headline number must be the **largest visual element** on the slide
- Each metric: number + label only — no explanatory text embedded with the number
- Numbers must be **rounded and human-readable** (use "3.2M" not "3,214,892")
- Context snippet is optional but must stay subordinate (small type, low contrast)
- No mixed narratives — the slide is about the numbers, not the story around them

## Cognitive Goal

Enable **sub-second quantitative comprehension**. The audience should register the number and its significance before they consciously decide to read the slide.

## Visual Expectations

- The number dominates — it is the first thing the eye finds
- Labels are clear but visually subordinate
- Grouping of related metrics is obvious
- Chart styling is unified and minimal (no chartjunk)
- Whitespace around the number amplifies its presence

## Avoid

- Paragraphs of interpretation
- Multiple competing focal points
- Excessive chart detail (gridlines, legends, 3D effects)
- Raw/unrounded numbers
- Mixing metric types without clear visual grouping

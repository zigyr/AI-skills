# Comparison Slide Grammar

## Use Case

Contrast two options, products, datasets, approaches, or viewpoints. The audience should immediately grasp the differences and the trade-offs involved.

Typical scenarios:
- Product A vs Product B
- Before vs After
- Current State vs Future State
- Option 1 vs Option 2 vs Option 3 (max 3-way)

## Narrative Role

- **comparison** — the core function, placing elements side by side
- **decision-support** — provides the evidence basis for a choice
- **clarification** — surfaces distinctions that may otherwise be blurred

## Layout Pattern

**50/50 side-by-side split** with a clear visual divider.

- Left and right panels of equal weight
- Each side contains minimal, parallel-structured items
- Visual divider (line, whitespace gap, or subtle color shift)
- Optional: center column for shared attributes or a vs label

Variants:
- 2-column text comparison
- 2-column with icon/image anchoring per side
- Table-style grid (for 3+ comparison dimensions)

## Information Density

**Medium.** Constrained by the split layout — each side has ~50% of the slide real estate.

Maximum per side:
- 1 header label
- 3–5 comparison points
- Each point: keyword + short phrase (no paragraphs)

## Content Constraints

- Comparison dimensions must be **parallel** — same categories on both sides
- Items per side must be **equal in count** to avoid visual imbalance
- Each point is a **fragment**, not a sentence
- Avoid nesting (no sub-bullets)
- If one side is clearly superior, the visual treatment should not bias before the evidence is read

## Cognitive Goal

Enable **instant differential comprehension** — the viewer sees both options and the gaps between them in a single glance. The comparison should feel complete and fair.

## Visual Expectations

- Clear visual separation between sides
- Differences immediately legible without reading every word
- Balanced visual weight (equal text mass per side)
- Consistent typographic treatment across both sides
- No decorative elements that favor one side

## Avoid

- Paragraphs of prose
- Asymmetric item counts per side
- More than one visualization per side
- Overlapping or ambiguous comparison dimensions
- Passive "on one hand / on the other hand" framing — be direct

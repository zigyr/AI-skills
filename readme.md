1. repos/

存原始 GitHub 仓库

```text
repos/
├── awesome-ui-skill/
├── ppt-skill/
├── research-agent/
```

不要乱改。

用：

`git clone`

管理。

以后：

`git pull`

更新。


2. registry/

自己做“统一入口”

例如：

```text
registry/
├── presentation/
├── ui/
├── writing/
├── cognition/
```

内部不是原始 skill。

而是：

```text
presentation/
├── skill.md
├── source.txt
├── adapter/
```

你自己的标准化版本。
